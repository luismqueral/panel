Panel design system

Status: Proposed. Every visual value here is philosophy-dependent. Hover and focus cells use data-force to show the state without a pointer.

Color

Neutral surfaces and text, one accent, semantic colors for meaning only.

Type

Five sizes. Sans for everything, mono for data.

Space and shape

An even spacing scale, two radii, and the focus ring.

Form grid

Fields carry data-width from the schema. Below 40rem every field is full width.

Icons

Original stroke icons in one sprite, sized to the text around them.

Button

Default, primary, negative, quiet. Small and icon-only sizes. Error: not applicable; destructive actions use the negative variant.

Text input

Label above, help and error below. Error uses aria-invalid and aria-describedby.

Textarea

Multi-line text. The markdown field adds a toolbar above it.

Select

Native select, restyled.

Radio

A fieldset of choices. Error is set on the fieldset.

Checkbox

Independent yes or no choices.

Toggle

A checkbox with role="switch". Takes effect when saved, like every other field.

Tag and tags input

A tag is a label the editor typed. The tags input collects them.

Status

A workflow state. A button when it changes the state, a span when it only shows it.

Tabs

Switch between groups in one view. A dot marks a tab holding fields with errors.

Breadcrumb

Where you are. The last entry is the current page. Disabled and error: not applicable.

Toolbar

A compact group of buttons, such as the markdown toolbar.

List

Rows with a title, subtitle, status, and meta. Error marks a row with a problem.

Spinner

Work in progress. Always paired with text for screen readers. Only a default state.

Loading posts

Dropzone and file

A label wrapping a file input, so it works by click, keyboard, and drop.

Dialog

A native <dialog>. Shown statically below; the button opens a real modal. Hover, focus, and disabled live on its buttons.

Delete this post?

This cannot be undone.

Drawer

A slide-over for quick edits that keep the page behind it. Shown statically; the button opens a real one.

Toast

A short message that confirms or warns. Tones: info, positive, notice, negative (the error state). Disabled: not applicable.

Empty state

What to show when there is nothing yet, or when loading failed (the error state). Hover and focus live on its button. Disabled: not applicable.
